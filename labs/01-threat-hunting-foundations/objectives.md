# Lab Objectives

1. Formulate a specific, testable hypothesis regarding the suspected credential compromise.
2. Interrogate the multi-source telemetry dataset (`multi_source_telemetry.csv`).
3. Identify anomalous after-hours logon events and subsequent living-off-the-land executions.
4. Correlate process creation with outbound network connections and DNS requests.
5. Build a forensic timeline from initial logon to command-and-control establishment.
6. Author a Sigma detection rule targeting the identified behavioral TTP.
